==================================================
 mdcheck · 使用说明
==================================================

【这是什么】
mdcheck —— Markdown 体检：查找失效链接、未闭合代码块、标题层级问题，顺便生成目录。

【怎么装】
需要 Python 3.8 或更高版本。把压缩包解压，在解压出来的文件夹里执行：

    python -m pip install .

装好后任何目录下都能用 `mdcheck` 命令。
不想装也能直接跑：python -m mdcheck.cli …（在解压目录里）

【怎么用】
    mdcheck .                    # 体检当前目录
    mdcheck README.md            # 只看一个文件
    mdcheck . --toc --write      # 顺手把目录更新进文件

【常用参数】
    -t, --toc            生成目录
    -w, --write          把目录写回文件（原地修改，先备份）
    --no-links           跳过链接检查
    --min-level 1        目录收录的最小标题层级
    --max-level 3        目录收录的最大标题层级
    -q, --quiet          只输出有问题的文件

【它的边界】
外链不检查（离线跑没法验证，硬查只会误报）；代码块里疑似 Markdown 的内容会被跳过。

【怎么确认是新版】
每次运行会在后台看一眼 GitHub，有新版本会打一行提示（查不到就安静跳过）。
不想让它查，设环境变量 MDCHECK_NO_UPDATE=1 即可关闭。
